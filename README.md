# Projeto-previs-o-do-tempo
Trazer condições climáticas de cidades. Basta digitar a cidade para obter as informações climáticas em tempo real. Visualize a temperatura, umidade, condições climáticas e muito mais. Desenvolvido com HTML, CSS, JavaScript e JSON. Acessa dados meteorológicos atualizados de um servidor confiável para fornecer informações precisas, utilizando JSON.
